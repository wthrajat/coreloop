# Product

## Register

product

## Platform

web

## Users

The primary user is a working software engineer with limited study time who
wants to broaden from a narrow domain into backend systems, cloud engineering,
applied AI, product engineering, communication, and practical sales. A small
group of invited friends uses the same service with separate private profiles,
topics, schedules, and progress.

## Product Purpose

Coreloop turns small weekday windows into sustained technical learning. It
delivers detailed, coherent lessons to Telegram, keeps important current
engineering developments outside the lesson schedule, and uses the web app only
to configure learning and understand progress. Success means users can explain
and apply useful concepts, not merely open more messages.

## Positioning

An always-on technical curriculum that favors usefulness, depth, and verified
current information while fitting into an engineer's existing day.

## Brand Personality

Calm, rigorous, useful. The product should feel like a dependable engineering
instrument: direct without being cold, detailed without becoming academic, and
encouraging without gamification or guilt.

## Anti-references

Do not resemble an endless news feed, a streak-driven language app, a crypto
hype dashboard, or an AI chat transcript. Avoid decorative dashboards,
attention-seeking motion, dense walls of configuration, and UI that competes
with Telegram as the reading surface.

## Design Principles

- Put usefulness and motivation before terminology.
- Make the next meaningful action obvious, especially in empty and failure
  states.
- Reveal configuration progressively while keeping every default explicit.
- Separate curriculum, current signals, and operational status so users know
  what kind of information they are seeing.
- Prefer trustworthy evidence and honest uncertainty over polished but weak
  output.

## Accessibility & Inclusion

Use readable contrast, visible keyboard focus, semantic controls, responsive
layouts, and reduced-motion behavior. Plain English must preserve precise
technical vocabulary. The first release is English-only.
